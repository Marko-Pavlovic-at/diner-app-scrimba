## Description

an app wiht 3 menu items from the array
on the right of the menu items there is a + button
when the button is clicked there should be a your order menu displayed on the bottom
it should say which items are being ordered with the price and an option to remove items and below that the total price
below that is a complete order button once its clicked a modal should pop up with name card number and cvv and a pay button
if one of the inputs is empty the user should get a prompt from the browser saying please fill in this field
after the user filled all forms and clicked pay the your order section should be replaced with a message thanks your order is on the way

## Requirements

- follow the design spec
- render menu options using js
- add item with plus button and remove item in the your order sections remove button
- payment modal with inputs and a pay button

## Stretch goals
